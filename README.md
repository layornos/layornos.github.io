# layornos.github.io

Personal homepage of Sandro Koch, served with GitHub Pages at https://layornos.github.io.

- `index.html` – the page (16-bit JRPG style)
- `shared/content.js` – all page text in English and German; edit wording here
- `shared/i18n.js` – language switch and small shared behaviour

No build step: plain HTML, CSS and JavaScript.
